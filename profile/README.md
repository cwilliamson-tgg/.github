# Tuesday Guild Games — Org Configuration

This repo controls org-wide GitHub configuration including:

- Workflow templates (reusable Actions for all repos)
- Issue and PR templates
- Security and contributing policies

## Repo Structure
```
.github/
├── ISSUE_TEMPLATE/          ← issue templates for all repos
├── workflows/               ← org-wide reusable workflows
├── workflow-templates/      ← starter workflows for new repos
└── profile/
    └── README.md            ← org homepage profile
```
